📌 PROJECT DESCRIPTION

This project is a Smart Mirror that displays your daily tasks, date, and time clearly.
Users can add tasks by typing or speaking in an Android app. 
These tasks are stored in Firebase Realtime Database.
The mirror then automatically retrieves the tasks and shows them on the screen instantly, keeping everything up to date.
-------------------------------------------
🎯 FEATURES

✅ Voice and text task input via Android app  
✅ Firebase Realtime Database integration  
✅ Real-time task display on the mirror  
✅ Date and time picker  
✅ Daily task planner view  
✅ Simple, user-friendly UI  
-------------------------------------------
⚙️ HOW TO SET IT UP

1. Open the Android app project in Android Studio  
2. Connect it to Firebase  
3. Run the app  
4. Set up MagicMirror on Raspberry Pi  
5. Add a module to show tasks from Firebase  
6. Power up Raspberry Pi,LCD Screen then enjoy your Smart Mirror!

-------------------------------------------
🧱 TECHNOLOGIES USED

- Android Studio (Java)

- HTML/CSS/JS for mirror display customization

ANDROID APPLICATION PAGES

1. Home Page  
2. Calendar Page

5. Task List Page
-------------------------------------------
📲 APPLICATION WORKFLOW

1. User opens the app  
2. Chooses to type or speak the task  
3. Enters title, details,time and date 
4. Clicks "Save" – task goes to Firebase  
5. Mirror gets the task from Firebase  
6. Mirror shows the task (title, details, time and Date)  
7. Tasks can be updated and the mirror will refresh
-------------------------------------------
WHAT THE MIRROR SHOWS

 Mirror displays:
 • Task title  
 • Task details  
 • Task date and time  
- Auto updates whenever a new task is added
